# 2026-08-01

## PyPI 发布 codewiki-plus v5.1.6

- 使用 `pyproject.toml`（setuptools 构建），包名 `codewiki-plus`，版本 `5.1.6`
- 在隔离 venv 中安装 `build` + `twine`，`python -m build` 生成 sdist + wheel
- 使用 PyPI API token（`__token__` 方式）通过 twine 上传到 https://upload.pypi.org/legacy/
- 发布成功，PyPI 页面：https://pypi.org/project/codewiki-plus/5.1.6/
- 构建时有 setuptools 弃用警告（license 用 TOML table + classifiers），不影响发布，2027-02-18 前需迁移到 SPDX 表达式
