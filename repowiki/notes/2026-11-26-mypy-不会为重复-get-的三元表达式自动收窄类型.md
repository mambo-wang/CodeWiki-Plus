## Background

类似下面的写法不会让 mypy 稳定收窄右侧表达式：

```python
meta = fm.get("metadata") if isinstance(fm.get("metadata"), dict) else {}
```

条件里检查的是一次 `get()` 调用，赋值时又发生了另一次 `get()`；mypy 仍可能报告 union-attr 或 arg-type 错误。`display` 等字段用同款三元表达式时也会出现相同问题。

## 正确做法

先取出并命名，再做类型守卫：

```python
meta = fm.get("metadata")
if not isinstance(meta, dict):
    meta = {}
```

后续只使用收窄后的 `meta`。`display` 等字段同样先赋值、再 `isinstance` 守卫。

## Rationale

这是 Python 动态字典与 mypy 静态收窄之间的常见落差；把条件检查和赋值拆开可以消除新错误，又不必用 `cast()` 掩盖真实类型。
