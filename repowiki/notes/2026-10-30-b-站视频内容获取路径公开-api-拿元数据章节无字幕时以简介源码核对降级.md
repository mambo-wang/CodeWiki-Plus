## Background

用户要求总结一个 B 站视频（【Mattpocock/Skills 全流程实战】）并生成文章。视频无公开字幕，最终文章基于元数据接口 + 仓库源码核对完成（产出 `articles/2026-10-23-mattpocock-skills-全流程实战拆解.md`）。

## Procedure（无需登录的公开接口链）

1. **解析短链**：`b23.tv/<code>` 302 重定向到 `bilibili.com/video/<BV号>`，用 `curl -s -L -o /dev/null -w '%{url_effective}'` 取真实地址。
2. **视频元数据**：`api.bilibili.com/x/web-interface/view?bvid=<BV号>`（带 `User-Agent: Mozilla/5.0`）返回完整简介 desc、时长、cid、发布时间、统计。UP 主手写的详细简介往往就是内容主干。
3. **章节与字幕**：`api.bilibili.com/x/player/v2?bvid=<BV号>&cid=<cid>` 返回 `view_points`（章节时间轴）与 `subtitle.subtitles` 列表；字幕为空数组即无公开逐字稿。
4. **评论**：`api.bilibili.com/x/v2/reply?type=1&oid=<aid>&sort=2` 可能返回空（需 wbi 签名），拿不到属预期。
5. **降级策略**：无字幕时，文章以「简介 + 章节时间轴」为主干，机制细节对照相关仓库的 README 与本地源文件核实，并在文末「资料来源」声明该边界，不编造视频原话。

## Rationale

值得持久化：这是「总结视频生成文章」类任务的可复用路径，明确了能力边界（拿不到音频/画面）与诚实的降级写法，下次遇到同类请求可直接走这条链。
