## 背景

MCP 聚类由宿主 Agent 决定，工具侧需要确定性诊断，但只累加组件 source_code 会漏掉完整文件体量，缺文件若按 0 token 处理又会误报微页。

## 核心内容

B5 按 leaf 完整 scope 文件分块计数，父模块取自身与后代文件并集；诊断微页、超大 leaf、同文件跨互斥 leaf、漏文件、未知或无路径组件、不可测文件。部分缺测只给下界，不判微页；空 leaf 单独处理。使用 [LazyComponentStore](../../codewiki/mcp/cache.py).items 的轻量元数据，并以文件签名做会话内计数缓存。

## 原因与边界

默认 1000/32000 token 阈值来自本仓 22 个 leaf 实测，不是通用结论。诊断统一 observe，不调用 LLM、不改树；schema/config/工作区异常降级 unavailable，不能把已保存树变成失败。
