## Background

MCP server 在模块 import 时就构造 `Server(...)` 并注册 prompts/resources（`codewiki/mcp/server.py` 里 `Server(...)` 与 `_register_prompts(server)` 均为模块级），所以语言初始化必须放在 `Server` 构造之前；反过来，任何在模块级求值的中文字面量都会在 import 那一刻被定死。

## 正确做法

- 模块级常量（如 `task_manager.py` 的 `_COMPACT_INSTRUCTION`、`wiki_index.py` 的 `_PAGE_TYPE_LABELS`）必须改成**惰性函数**，在调用时才 `t()` 取词，否则 `set_lang()` 之后仍是旧语言。
- 模板路径同理：`init_wiki.py` 的 schema / review_checklist 模板要在**拷贝时**按当前语言解析，不能固化成模块级常量（`schema_generator.py` 的 `_CONFIG_PATH` 曾就是这种常量）。
- 不便在模块顶部引入 i18n 的文件（如 `wiki_lint.py`），改用**函数内局部 import**，避免 import 期依赖与语言固化。

## 验证

语言相关的断言要覆盖「切换后再取值」，只测默认语言无法发现固化问题。
