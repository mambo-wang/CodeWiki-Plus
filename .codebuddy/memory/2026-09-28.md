### 关键教训

- **本机 curl.exe 版本 7.55.1 太老**，不支持 `-K` 配置文件的 `form-string`/`form-file` 长选项（curl 7.84+ 才支持）。用 `-K` 配置文件传 multipart 表单时，字段被静默忽略，curl 发了空 POST，PyPI 返回 405/400。
- **绕法**：用 Python 构造完整的 multipart/form-data body（含 boundary、所有元数据字段、文件内容）写到 .bin 文件，再用 `curl.exe --data-binary @body.bin -H "Content-Type: multipart/form-data; boundary=..."` 发送。
- **PyPI legacy API 字段名用下划线**（`metadata_version`），不是连字符（`metadata-version`）。虽然 METADATA/PKG-INFO 头用连字符，但表单字段必须转成下划线，否则 PyPI 报 "None is not a valid metadata version"。
- **PyPI legacy API 必须字段**：`:action=file_upload`（没有这个字段 PyPI 返回 405 Method Not Allowed）。
