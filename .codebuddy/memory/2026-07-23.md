## 修复 CodeWiki-CN 的 `pip install -e .` 失败
- 根因：构建隔离（build isolation）阶段 pip 试图联网下载 `setuptools>=68.0.0`，但环境离线/DNS 解析失败（Errno 8）。实际上 `setuptools 82.0.1` 及全部项目依赖（click/openai/pydantic/litellm/tree-sitter/jieba...）本就已安装。
- 修复命令：`pip install -e . --no-build-isolation`（复用已安装 setuptools，跳过联网构建依赖下载），已验证安装成功、`codewiki --help` 正常。
- 残留噪音：conda 环境 `/Users/kirito/miniconda3/lib/python3.13/site-packages/~etuptools`（root 所有，中断卸载遗留），pip 每次报 `Ignoring invalid distribution ~etuptools` 警告，无害；如需清除需 `sudo rm -rf`。
- 结论：此后在本机离线安装该项目，统一使用 `--no-build-isolation`。
