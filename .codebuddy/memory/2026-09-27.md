## HTTP 接口自动映射 MCP 工具调研（问答）
- 用户问是否有把 HTTP 接口自动映射为 MCP 方法的工具。答复要点：主流路线是 OpenAPI/Swagger → MCP 自动生成；工具分三类——开发库（FastMCP `from_openapi`、mcp-swagger）、网关/平台（Higress、Nacos 3.x MCP Registry、Kong/Traefik Hub、Cloudflare MCP Server Generator、Zapier）、API 厂商官方（Stripe MCP、Postman MCP）。
- 关键限制：需先有 OpenAPI 规范；自动映射只做 endpoint→tool 一对一，鉴权/分页/组合调用需人工；大 API 需按 tag/path 筛选 tool 子集。用户尚未表明具体落地意图，若后续跟进再补选型结论。
