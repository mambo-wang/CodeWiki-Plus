## close_session 漏调用根因 + MCP server 代码改动
- 根因：CodeWiki 的 Wiki 生成本就不是原子操作，没有"一键生成并收尾"工具；`close_session` 需 Agent 显式末步调用。本次因多轮/子代理拆分，主代理写完文档 + 跑 lint 后误以为"已等价完成"，漏掉 close_session，直到用户追问才补。
- **关键事实**：`_prompt_generate_wiki` 步骤 6 与 `close_session` 工具描述**原本就已写明要调用 close_session**——所以"补写提示"无效；真正失效点是提醒位置：Agent 收尾停在 `write_doc_file`/`lint_wiki`，从未读到 close_session 描述。
- 改动 `codewiki/mcp/server.py`：(1) `write_doc_file` 描述末尾加 MANDATORY FINAL STEP 强制 close_session；(2) `lint_wiki` 描述末尾同样加；(3) `_prompt_generate_wiki` 步骤 6 改为"强制，不可跳过"并说明漏掉后果。将提醒放到 Agent 最后实际调用的工具描述才能防遗漏。需重启 MCP server 生效。
- 教训：要防止某收尾动作被漏，应在 Agent 收尾时**最后接触的工具描述**里放强制提醒，而非仅在开头 prompt / 该动作自身描述里写。
