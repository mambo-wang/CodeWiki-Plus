  ## Agent Brief

  **Category:** enhancement
  **Summary:** 新增 MCP 工具 `capture_conversation`，把一次 Agent 对话的原始 turns 落盘到 `repowiki/raw/<session>.md`。

  **Current behavior:**
  CodeWiki-CN 已有 `ingest_note` / `confirm_note` / `reject_note` 知识飞轮与 `query_wiki` 检索，但**没有**任何从对话流采集原始 turns 的入口。对话经验散落在聊天记录里，Session 结束即丢失。

  **Desired behavior:**
  新增 MCP 工具 `capture_conversation`，接收一个 session 的原始对话 turns（含 session id、每条 turn 的 timestamp 与 actor 标签 user/assistant），以 Markdown 写入 `repowiki/raw/<session>.md`。该目录已存在，无需新建。工具返回写入的文件路径/标识，供后续 `distill_conversation` 引用。写入应是幂等的：同一 session 重复调用应覆盖而非追加重复内容。

  **Raw 生命周期（重要设计约束）：** `repowiki/raw/` 是**暂存区，不是知识库**，不进入 `query_wiki` 检索，因此文件数量多**不会拖慢查询**，只占用磁盘。为防止无限膨胀：
  - `capture_conversation` 仅负责落盘；**不**在此处做清理。
  - 蒸馏完成后由 `distill_conversation`（T2）在草稿全部确认/拒绝后**删除对应 raw 文件**（best-effort）。
  - 提供 `keep_raw: bool` 入参（默认 False），审阅者可在审计特定对话时保留。
  - 提供可配置保留上限（默认 7 天），自动清理未被蒸馏的陈旧 raw 文件。
  - 真正的知识源是 `notes/` 中已确认的 note，raw 永不作为 source of truth。

  **Key interfaces:**
  - 新 MCP 工具 `capture_conversation`，入参为对话 turns 结构（session_id, turns[{role, content, timestamp}]），出参为 `raw_path`。
  - 注册到现有 MCP server（registry 模式），与其他工具（如 `ingest_note`）一致暴露。
  - 复用 `repowiki/raw/` 目录与现有 workspace 会话概念（与 `ingest_note`/`query_wiki` 的作用域一致）。
  - 不加新的持久化层——仅落盘 Markdown 文件。

  **Acceptance criteria:**
  - [ ] 调用 `capture_conversation` 后，`repowiki/raw/<session>.md` 存在且含全部 turns 及时间戳/角色标签。
  - [ ] 同一 session 重复调用为覆盖写，不产生重复 turns。
  - [ ] 工具返回可被 `distill_conversation` 直接消费的 `raw_path`。
  - [ ] 工具在 MCP server 注册并可通过 handler 表面调用（不依赖 UI）。
  - [ ] 有一条 handler 层测试覆盖成功写入与幂等覆盖。
  - [ ] `keep_raw=True` 时文件保留；默认情况下文件可在蒸馏完成并被 T2 清理（行为由 T2 承载，此处仅保证入参透传）。
  - [ ] raw 文件**不参与** `query_wiki` 检索（由现有索引逻辑保证，T1 不改动索引路径）。

  **Out of scope:**
  - 自动触发逻辑（何时采集由 T0/后续决定，本任务只实现工具本身）。
  - L0→L1 蒸馏（见 T2）。
  - 任何 TAM 代码或 Node 依赖。
