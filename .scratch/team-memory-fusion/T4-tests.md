  ## Agent Brief

  **Category:** enhancement
  **Summary:** 为对话→Wiki MVP 补 handler 层测试与 LLM 提取 golden-set，防幻觉回归。

  **Current behavior:**
  现有 `codewiki/mcp/tools/` 已有 `handle_ingest_note` / `handle_confirm_note` 测试惯例，但对话采集/蒸馏链路无测试。提取质量（幻觉风险）无回归防护。

  **Desired behavior:**
  新增测试，遵循现有 MCP 工具测试模式：
  (a) `capture_conversation` handler 测试：成功写入 + 幂等覆盖。
  (b) `distill_conversation` handler 测试：给定 raw 产出正确 `note_type` 的草稿。
  (c) 集成测试：贯穿 `capture_conversation` → `distill_conversation` → `confirm_note` → `query_wiki`，验证草稿经确认后才可检索、且 `query_wiki` 能取回对话笔记。
  (d) golden-set：一小批已知 raw 对话 → 预期提取笔记，捕获 LLM 提取回归（幻觉/漏提）。
  测试 fixtures（样例 raw 对话）置于 `tests/`。

  **Key interfaces:**
  - 沿用 `codewiki/mcp/tools/` 现有测试 fixtures/断言风格。
  - 通过 MCP handler 表面测试，而非内部函数（参照 spec 的"测外部行为不测内部"）。

  **Acceptance criteria:**
  - [ ] `capture_conversation` handler 测试覆盖成功写与幂等。
  - [ ] `distill_conversation` handler 测试覆盖 note_type 正确性与 draft 状态。
  - [ ] 一条端到端集成测试覆盖 采集→蒸馏→确认→检索。
  - [ ] 至少 3 条 golden-set 样例验证提取质量。
  - [ ] 全部测试可独立运行且不依赖外部实时 LLM（用 mock/stub 模型响应或固定 fixture）。

  **Out of scope:**
  - 性能/负载测试。
  - UI 测试。
