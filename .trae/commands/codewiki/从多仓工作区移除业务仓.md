# 从多仓工作区移除业务仓

按子目录名把业务代码仓库从 harness 工作区移除：事务式清理 bootstrap.sh/ps1 登记表、.gitignore、repo-map.md，并删除本地 clone 目录（不可恢复）。

调用 MCP 获取完整工作流并按其执行：

```
get_prompt(name="remove-workspace-repo", arguments={"workspace_path": ".", "name": "<name>"})
```

返回的工作流包含分阶段指引，逐步照做即可。
不要凭记忆执行——模板真源在 `codewiki/mcp/prompts.py`，以 `get_prompt` 返回内容为准。
