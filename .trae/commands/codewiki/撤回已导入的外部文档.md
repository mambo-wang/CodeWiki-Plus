# 撤回已导入的外部文档

把 ingest_source 导入的源文档从知识库移除或标记退役：查 source_registry.json 确认标识符 → dry_run 预览 → 用户确认 → retract_source（flag_stale 只标记并保留文件 / remove_refs 移入 .trash 并清理 source_refs）→ lint 复核残留引用。

调用 MCP 获取完整工作流并按其执行：

```
get_prompt(name="retract-source", arguments={"name": "<name>", "repo_path": "."})
```

返回的工作流包含分阶段指引，逐步照做即可。
不要凭记忆执行——模板真源在 `codewiki/mcp/prompts.py`，以 `get_prompt` 返回内容为准。
